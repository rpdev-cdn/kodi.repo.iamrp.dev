# Kodi Add-on Repository (`kodi.repo.iamrp.dev`)

Official distribution repository and Kodi File Manager ingress for first-party **RPDevs** Kodi add-ons.

- **Production URL**: `https://kodi.repo.iamrp.dev/`
- **Addon Manifest**: `https://kodi.repo.iamrp.dev/addons.xml`
- **Installer ZIP**: `https://kodi.repo.iamrp.dev/repository.rpdevs-1.0.0.zip`

## Hosted First-Party Add-ons
- `script.service.megacloud`: Standalone local HTTP decryptor for Megacloud/Vidcloud.
- `script.service.flaresolverr`: Local Turnstile / Cloudflare challenge bypass daemon.
- `metadata.anime.otaku.python`: High-performance anime metadata scraper and S01E01 standardizer.
- `repository.rpdevs`: Core repository installer.
