🎯 How to Install in Kodi

Step-by-step Kodi File Manager installation:

  1. In Kodi, open Settings (gear icon) → File Manager.
  2. Select Add source, click <None>, and enter this exact URL:
https://kodi.repo.iamrp.dev/
  1. Name the media source RPDevs and click OK.
  2. Go back to Kodi home → Add-ons → Install from zip file (enable Unknown Sources if prompted).
  3. Select RPDevs → repository.rpdevs-1.0.1.zip.
