🎯 How to Install in Kodi

Option 1: Add as Kodi File Manager Source (Recommended)

  1. In Kodi, open Settings (gear icon) → File Manager.
  2. Select Add source, click <None>, and enter this exact URL:
https://kodi.repo.iamrp.dev/
  1. Name the media source RPDevs and click OK.
  2. Go back to Settings → Add-ons → Install from zip file.
  3. Select RPDevs → repository.rpdevs-1.0.0.zip.

Option 2: Direct Installer ZIP Download

Download the repository installer package directly and install via file transfer:

⬇️ Download repository.rpdevs-1.0.0.zip
